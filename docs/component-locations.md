## 시각화 전 확인할 점

- 관세청 HS 지침은 품목분류와 예시를 설명하며 보편적인 차량 장착 좌표를 정하지 않습니다. 지도 점은 특정 기준 차량의 부품도에 맞춰야 합니다.
- 특정 차량을 기준으로 삼지 않는다면 ‘일반 승용차의 개념도’임을 화면에 밝히고, 차종별로 달라지는 품목은 정확한 점 대신 시스템 영역으로 표시합니다.
- 잔여·복합 코드(`8708290000`, `8708309000`, `8708999000`, `기타`)는 코드명만으로 하나의 위치를 정하지 않습니다. 실제 포함 품목을 따로 선택할 수 있을 때만 그 품목 위치를 보여주는 편이 정확합니다.

## 대조한 자료

- 프로젝트 품목 정의: `utils/constants.py`의 `CODE_GUIDE_GROUPS`.
- [관세청 자동차 부품 품목분류 표준해석 지침 발간 안내](https://www.customs.go.kr/kcs/na/ntt/selectNttInfo.do?mi=2891&nttSn=10107316&nttSnUrl=search): HS는 품목분류 체계이며 자동차 품목은 세부 품목별 설명·사진을 제공한다고 안내합니다. 부품 분류 자체가 장착 좌표를 제공하지는 않습니다.
- [Toyota SRS components owner’s manual, p. 69](https://www.techinfo.toyota.com/t3Portal/document/om-s/OM47568U/pdf/OM47568U.pdf?locale=en&siid=1761524435196&sisuffix=ff): 특정 Toyota 차량의 전면 에어백·센서·좌석 위치를 도식화한 사례입니다.
- [Honda brake booster repair procedure, 2021–23 Passport / 2021–22 Pilot / 2020–23 Ridgeline, pp. 8–11](https://static.nhtsa.gov/odi/rcl/2023/RCRIT-23V458-7840.pdf): 부스터와 마스터실린더가 엔진룸·브레이크 페달 연결부에 있는 특정 차종 사례입니다.
- [Western Star service bulletin, front brake drums and linings](https://static.nhtsa.gov/odi/tsbs/2012/SB-10044782-4293.pdf): 특정 대형차 전륜 브레이크 사례이며 일반 승용차 배치의 근거로 확대 적용하지 않습니다.
- [U.S. DOE AFDC, hybrid electric vehicle components](https://afdc.energy.gov/vehicles/how-do-hybrid-electric-cars-work): 동력계가 엔진·모터·변속기 조합에 따라 달라짐을 설명합니다. 축·변속기·클러치의 보편적인 위치를 정하는 자료는 아닙니다.

**결론:** 현재 초안의 대표 위치 중 일부는 개념도에 쓸 만한 관행적 위치지만, 20개 항목을 모두 정확한 장착 좌표로 검증한 것은 아닙니다. 실제 핫스폿을 확정하려면 기준 차종·연식·구동 방식과 그 차량의 부품도를 먼저 정해야 합니다.
